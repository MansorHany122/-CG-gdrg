温水猫CG角色训练：全流程避坑与风格统一落地实战总结
很多温水猫CG角色的训练项目，做到最后很容易出现前面所有环节都做得不错，但是最终出来的成片效果完全跑偏的问题：要么毛发质感和形体风格不匹配，要么光影氛围和角色的萌感完全脱节，整个项目的风格统一性彻底失控。这些从大量实战训练里总结出来的避坑经验，能帮你少走很多弯路，从头到尾保证整个项目的风格统一，顺利产出高质量的最终作品。

第一个最常见的坑，就是前期形体阶段过度追求写实，把肌肉和骨骼的结构做得太硬太突出，做到后期渲染阶段才发现，整个角色的气质偏向凶猛的野猫，完全没有温水猫软乎乎的感觉。你在形体起稿的阶段，就要时刻把“所有尖锐棱角全部圆化”作为第一原则，哪怕解剖结构上有骨骼凸起的位置，也要用厚厚的脂肪和毛发把它盖住，从第一步开始就把软萌的气质定下来，不要等到后期渲染阶段再试图靠材质和光影去修改，根本救不回来。

第二个高频坑，就是毛发细节做得过度，大量的发丝细节完全抢了形体和表情的风头，观众的注意力全部放在数毛上，完全注意不到角色的表情和动态，整个角色的治愈感反而被削弱了。你要时刻记住，毛发是为角色的整体气质服务的，不是用来炫技的工具，恰到好处的成簇毛发表达，远好过密密麻麻的根根分明的超写实发丝，不要为了展示技术能力，破坏了整个角色的软萌风格。

第三个坑，就是后期渲染的时候盲目加大量高饱和的特效和滤镜，把整个画面的柔和光影全部破坏掉，原本温暖治愈的氛围直接变得花里胡哨。温水猫的最终画面，做减法永远比做加法重要，你要尽可能把多余的元素全部去掉，让观众的注意力完全集中在角色本身，干净柔和的画面，反而能最大化传递角色的治愈感。

温水猫这类CG角色的创作，从来不是比拼谁的技术更复杂、谁的细节更多，它最核心的目标是传递温暖松弛的情绪，让看到它的人能瞬间卸下压力，感受到软乎乎的治愈感。把全流程每一个环节的细节都围绕这个核心目标走，你就能做出一个能真正打动人心的优秀温水猫CG角色作品。
